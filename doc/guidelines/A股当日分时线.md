## 最值得重点研究的8种形态

| 形态  | 潜在买入点 | 潜在卖出或退出点 |
| --- | --- | --- |
| 01 强势单边上涨 | 首次回踩均价线并企稳 | 跌破支撑，或上涨动能明显减弱 |
| 02 阶梯式上涨 | 回踩前一个平台不破 | 新平台跌破，或冲高明显受阻 |
| 04 V形反转 | 重新站稳均价线并确认反转 | 前高附近受阻或再次失守支撑 |
| 07 低开高走 | 收复均价线并保持强势 | 前高附近或跌回均价线下方 |
| 09 横盘向上突破 | 放量突破平台，最好回踩确认 | 跌回平台内，或上涨后出现衰竭 |
| 13 假跌破后收复 | 快速收复箱体下沿且不再失守 | 箱体上沿附近，或再次跌破下沿 |
| 14 午后放量拉升 | 突破后第一次有效回踩 | 上攻受阻或跌回突破位置 |
| 17 双底W形 | 突破颈线并确认 | 前期压力位附近或跌破颈线 |

## 原则上优先观望的形态

| 形态  | 观望原因 |
| --- | --- |
| 03 早盘冲高回落 | 容易在高位追涨后被套 |
| 05 倒V形反转 | 趋势由强转弱 |
| 06 单边下跌 | 未出现可靠的止跌确认 |
| 08 高开低走 | 价格不断走弱 |
| 10 横盘向下破位 | 支撑失守，可能继续下探 |
| 12 假突破诱多 | 突破缺少持续性 |
| 15 尾盘急拉 | 可供确认的交易时间不足 |
| 16 尾盘跳水 | 存在进一步下跌风险 |
| 18 双顶M形 | 上攻失败、跌破关键支撑 |
| 20 下跌后低位横盘 | 无法确定是否已经见底 |
| 21 均价线反复拉锯 | 方向不明，容易反复触发错误信号 |
| 22 急跌后弱反弹 | 反弹不一定代表趋势反转 |
| 23 早盘涨停后开板 | 波动和流动性风险较高 |
| 24 午后突破失败 | 容易出现追高后的回撤 |
