1、能识别现在分时状态的情况，要能识别出今天的基调  
2、在集合竞价阶段能找到当天火热的股票和板块  
3、能在分时图当中识别当天的低点并且后续能上涨的可能性的股票

4、能提前一天给出该股票价格的最高点和最低点的预测

5、要做的策略就三个：  
5.1、寻找强势板块的强势股  
5.2、寻找在14.20的时候，出现超跌，第二天反弹的股票  
5.3、确定当天合适的买点  
 

## 先把目标收口

| 策略  | 赚什么 | 关键时点 | 仓位  |
| :--- | :--- | :--- | :--- |
| 5.1 强板块里的强票 | 当天上涨 | 竞价确认 → 9:30–10:40 买点 | 主仓（当天） |
| 5.3 当天买点 | 把 5.1 做成可成交的点 | 只在 10:40 前（或确认后的回踩） | 跟 5.1 |
| 5.2 14:20 超跌次日反弹 | 次日修复，不是当天抄底 | 14:20 扫描，14:40 后才允许小仓隔夜；次日竞价确认 | 观察仓，错了也伤不了 |

你们《短线炒股心得》写得很清楚：中间 10:40–14:40 只卖不买；隔夜只埋伏「今天已经在涨」的方向；禁止隔夜扛高潮龙头、禁止埋伏今天大跌的超跌。  
5.2 要能赚钱，必须做成「中等跌幅 + 不是资金抽干 + 尾盘不再加速杀 + 次日竞价确认」，不能做成 14:20 全市场跌幅榜一把梭。

第 4 点「提前一天预测最高价最低价」不要当主信号。点位预测稳定打不准。正确用法是：给出区间（如 ATR 通道、昨日高低、开盘缺口），用来设止损/止盈，不用来决定买谁。

## 能力层怎么接到现有系统

你们已经有半成品，缺的是「串成一条流水线 + 硬过滤」，不是从零写模型。

1\. 今天基调（9:30–10:00 定调）

陈小群那条和分时图 24 形态是一回事：前 30 分钟定全天主力意图。配三层，缺一层不准开 5.1：

- 指数：高开低走 / 低开高走 / 单边 / 震荡（用上证+创业板 1 分钟，相对昨收和分时均价）。
- 板块：现成工具 `sector_intraday__l2_tone`（二级行业日线排序 + 成分分时合成）。基调 = 今天前 3～5 名板块是否同向、是否站上均价。
- 个股形态：把 `doc/guidelines/A股当日分时线.md` 的 24 类做成规则分类器（相对开盘、均价线、是否创新高/新低、量能）。  
    只允许跟 8 种可买形态（强势单边、阶梯上涨、V 反、低开高走、横盘上破、假跌破收复、午后放量拉升、W 底）。  
    早盘冲高回落、高开低走、单边下跌、假突破、尾盘急拉/跳水 → 基调记为「空」或「只卖」。

10:00 前基调是「空/诱多」，当天 5.1 整策略停机，只允许减仓。这是降回撤最有效的一刀。

2\. 集合竞价找当天热的股票和板块

现成：`auction_screen__mainboard_buy`（昨强 ∪ 昨涨停，09:20–09:25 成交额 P95 且价升）。

要改的配置：

- 输出不能只是个股。按东财二级/三级把竞价额、价升家数聚成板块热度，5.1 的宇宙必须是「热板块 ∩ 热个股」。
- 竞价是确认开关，不是买点。弱开、板块集体软 → 隔夜仓按计划处理（心得规则六）。
- 覆盖不足（`incomplete=true`）不准下「今日无热点」的结论，先补 `get_mins include_auction=true`。

3\. 分时低点且后续还能上

不要找「今天最低价」。要找结构低点：回踩均价不破、回踩平台不破、V 反重新站上均价。这就是 5.3。

现成可复用：

- T0 的 `t0_intraday__load_day` + `hit-test`：检验「低点附近有没有可成交信号」，禁止用 nearest（事后最接近极值）当实盘规则，只用 first。
- `intraday_turning_service`：5 分钟三分类（先上/先下/中性）+ ATR 障碍，不是回归出高低点。只当 5.3 的滤镜：买点出现时若模型偏向 DOWN_FIRST，放弃。

买点必须同时满足：板块仍强、个股在 8 种可买形态里、价格在分时均价之上或刚收回、时间在 10:40 前。

4\. 「提前一天的最高最低」怎么用

做成区间预报，不要报一个价：

- 上沿：昨高、ATR×k、涨停价三者取近
- 下沿：昨低、ATR×k、开盘缺口
- 方向：心得规则六四步（市场温度 → 主线 → 有没有余粮 → 催化确认）+ 板块资金，只判断「明天更可能走强还是走弱」

隔夜仓的止盈看上沿、止损看下沿；选股仍看 5.1/5.2 名单，不看预测点。

## 三条策略在系统里怎么跑

### 5.1 强板块的强势股（当天主利润）

流水线按时间钉死：

1.  前一日收盘：主线、余粮、不要高潮龙头（规则六）。隔夜最多观察仓。
2.  09:20–09:25：竞价热板块 + 热个股。弱开的隔夜仓处理掉。
3.  09:30–10:00：指数+板块+形态定基调。基调空则 5.1 全天不开新仓。
4.  10:00–10:40：只在热板块里、可买形态上、均价线上方给买点（5.3）。
5.  10:40 后：只卖不买。浮盈按心得：隔夜赚钱开盘先走一半；高开 ≥3% 先走一半以上。
6.  当天卖点：放量跌破均价半小时不收、板块转弱、形态变成冲高回落/倒 V。

选股过滤（提高准确率）：

- 必须在当日热板块里（先板块后个股）。
- 昨天已经在涨或竞价价升（心得：能直接拉的，昨天也得在涨）。
- 主板优先，现有竞价工具已经排除科创/创业/北证/ST。
- 量能跟上，假突破（形态 12）直接剔除。

### 5.2 14:20 超跌 → 次日反弹（次利润，小仓）

14:20 只扫描不下单。买点收到 14:40 之后（心得买入窗），隔夜必须小。

筛选要同时满足，缺一条就丢掉——这是「不是外力抽干」的可执行定义：

| 要   | 不要  |
| :--- | :--- |
| 板块跌幅大（当日板块分位靠前） | 板块跌停潮、资金净流出极端（板块资金「抽干」） |
| 个股跌幅中等（例如相对板块中位，避开最惨 10%） | 个股跌停、巨大阴、缺口向下、停牌复牌、公告雷 |
| 14:20 后到 14:40 不再加速创新低，抛压变缓 | 尾盘仍在跳水（形态 16） |
| 指数不是单边崩 | 大盘瀑布日整策略停 |
| 次日竞价不弱开 | 弱开、低开、板块软 → 开盘按失败处理，不扛 |

「跌幅比较中」= 跟跌但不领跌。领跌的是出货/雷，中等跌的才是错杀修复。这和规则二、规则六不打架：不是抄今天被砸的高潮票，是在杀跌板块里挑没崩完、尾盘止跌的中军。

次日开盘：赚钱走一半；弱开离场，但等回抽，不在瀑布里砸（规则八）。

### 5.3 当天买点（为 5.1 服务）

买点不是「看起来在低」。用 24 形态里那 8 个：

- 强势单边：回踩均价企稳
- 阶梯上涨：回踩前平台不破
- V 反 / W 底：收回均价或突破颈线
- 低开高走：收复均价后保持强
- 横盘上破：放量突破，最好回踩
- 假跌破：快速收复下沿
- 午后放量拉升：只在 14:40 后才允许跟（否则违反中间只卖不买）

T0 四法可以当「低点质量」检查，不能当选股器。`nearest` 命中高低只用于复盘，实盘只用第一次信号。

## 怎么提高准确率、压回撤

系统上加这些硬开关，比再训一个模型有用：

1.  基调开关：10:00 前指数+热门板块不同向，5.1 仓位为 0。
2.  时间开关：新开仓只在 10:40 前和 14:40 后。14:20 只有 5.2 的名单，没有委托。
3.  宇宙开关：5.1 只能买竞价热板块里的票；5.2 只能买「大跌板块里的中等跌幅」。全市场扫雷会把准确率打穿。
4.  形态开关：不在 8 种可买形态里，不允许买。诱多、高开低走、假突破一律观望。
5.  仓位：5.1 单票限仓、板块限仓；5.2 总仓远小于 5.1。隔夜失败只允许亏「小仓」。
6.  卖出写死：均价线下不砸、开盘急转等回抽、浮盈先走一半、硬止损按心得规则九。回撤主要来自「该走不走」和「中间时段手痒」。
7.  不要用高低点预测做开仓。 预测错了会在最差位置加仓。区间只用于止盈止损。
8.  先纸面再实盘：5.1、5.2 分开记账。看的是：竞价确认后的胜率、盈亏比、最大回撤，不是回测里打中最高最低的次数。
