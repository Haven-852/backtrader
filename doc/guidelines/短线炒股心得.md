# 短线炒股心得

> 本文是实盘操作备忘，不是完整策略说明书。先记清「什么时候必须走、什么时候不准买」，再谈轮动方向。

---

## 总原则

1. **先看板块资金，再看个股。** 前一交易日主流板块的抛压，往往比当天开盘的情绪更提前。
2. **轮动要快，抄底要慢。** 高位板块一旦出现大量抛单，当天或次日开盘就要完成切换；大跌之后则必须等底部确认，禁止开盘抢反弹。
3. **能直接拉升的票，前提是前一天已经在涨。** 弱转强、缺口反包，不是开盘瞬间能判断的，不要用「今天可能会涨」去对抗「昨天已经在跌」。
4. **卖在均线上方，不在均线下方砸。** 日内分时均价线（日内均线）是强弱分界：抛出尽量等价格回到均线之上，不要在均线下面把货交出去。
5. **隔夜一赚钱，开盘先走一半。** 短线第二天开盘已经浮盈，必须先抛 1/2 锁定，剩下 1/2 才允许继续奔跑。全部留着跑，等于把已到手的利润重新变成风险。
6. **市场暴击、科技大跌，不抄科技，看轮动名单。** 优先银行，其次航运港口、焦炭、煤炭开采、军工电子、房地产、贵金属。科技这边只出不进。
7. **次日热点只埋伏「今天已经在涨、还没走完」的方向。** 隔夜仓必须小；竞价是确认开关，弱开就按计划处理。不猜全新题材，不隔夜扛高潮龙头，不埋伏今天大跌的超跌。
8. **两个买入窗：10:40 前、14:40 后；中间只卖不买。** 盘中最容易做错的时间，往往不是开盘和尾盘，而是两者之间的那段。
9. **开盘急转直下，先停手，不在瀑布里砸。** 想立刻卖掉的冲动，往往出现在当天最差的价格上。决定可以立刻做，单子要等回抽。
10. **截断亏损，让利润奔跑。** 隔日短线最容易踩处置效应：盈利怕回吐急着兑现，亏损不肯认错死扛。卖出必须盘前写死，不能第二天凭感觉。
11. **高开 3% 以上，开盘先跑一半以上。** 大概率是有人在兑换前一天的筹码。规则四的「留一半跑」在这里要加速：先锁大头，剩下才允许看。

## 规则一：半导体抛压出现后，切向银行与春分动力

### 1.1 核心动作

当前一交易日发现**主流半导体出现大量抛单**时：

1. **尽快清仓半导体相关股票**，不要等反抽、不要幻想「再看一眼」。
2. 资金立刻转向观察并布局：
   - **国有大型银行**（工农中建交邮等）
   - **股份制银行**（招行、兴业、浦发、中信、民生等）
   - **春分动力**相关股票（按自己的观察清单执行；若实际指定的是个股「春风动力」603129，则单独跟踪该标的）

这是**板块轮动**，不是个股抄底。半导体这边的抛压，往往意味着当天风险偏好在收缩；银行（尤其是大行、股份行）更接近避险与配置资金的去处。提前看到「半导体在出、银行还没完全启动」，才能把轮动做在别人反应之前。

### 1.2 如何判断「大量抛单」（前一日信号）

满足越多条，越要当回事，不要等第二天开盘再犹豫：

- 半导体板块指数收阴，且**成交量明显放大**（相对近 5～10 日均量）
- 龙头与中军同步走弱，不是一两只票的独立利空
- 分时上出现持续压单、尾盘加速下跌或尾盘砸盘，而不是早盘洗盘后收回
- 高位票放量滞涨后转跌，比低位阴跌更危险——前者是主力在出
- 同一日银行、红利、高股息方向相对抗跌或已经有资金进场，轮动更干净

**注意：** 单只个股的大单，不足以代表「主流半导体在抛」。要看板块整体，以及龙头是否一起走。

### 1.3 执行节奏

| 时点 | 动作 |
|:-----|:-----|
| 前一日收盘后 | 确认半导体是否放量抛压；列出要清的半导体持仓、要看的银行与春分动力标的 |
| 次日集合竞价 / 开盘初 | 半导体若低开或弱开，按计划减仓/清仓，不要等盘中「再给你一次机会」 |
| 切换窗口 | 优先看银行里走势更稳、没有补跌的标的；春分动力按清单单独判断强弱，不和半导体绑在一起 |
| 当日若半导体暴力反抽 | 仍以「已经出现大量抛单」为准，反抽是减仓窗口，不是重新加仓理由 |

### 1.4 为什么是银行，而不是随便换一个成长板块

短线里，半导体属于高弹性、高风险偏好品种。一旦出现集中抛压，资金通常不会马上再去另一个同样高波动的成长方向，而更容易先去：

- 流动性好、有配置盘的大行
- 有弹性但仍偏金融属性的股份行
- 自己预先盯住的「春分动力」这类轮动承接标的

所以这是**已知的两者轮动**：半导体（进攻/高beta）↔ 银行 + 春分动力（承接/相对防守）。不是每天都要做，只有「半导体昨夜已经在大量出货」这一天才强制执行。

### 1.5 这条规则的边界

- 半导体只是阴跌、缩量、板块内部分化，**不算**大量抛单，不必机械清仓。
- 银行如果当天也在补跌、没有承接，不要为了「必须轮动」而去接飞刀。轮动的前提是：**这边在出，那边接得住。**
- 清仓半导体是风控，买银行是观察后的动作。可以先出来，不必同一分钟打满另一边。

## 规则二：大跌之后等底部，开盘不做；能直接涨，必须昨天也在涨

### 2.1 核心动作

如果遇到**股票大跌**（个股或板块突然深跌、缺口向下、恐慌盘涌出）：

1. **等待时间**，先看什么时候真正出现底部，再动手。
2. **不要在开盘时操作**——大跌后的开盘，定价最乱，假信号最多。
3. 只有一种情况，短线才允许「开盘附近就跟」：**前一天本身也在涨**。能直接拉起来的票，通常是延续，不是逆转。

一句话：

> **大跌后的第一反应是空仓等待，不是开盘抄底。**
> **追涨可以发生在「昨天已经涨」的延续里；不能发生在「昨天刚杀跌」的幻想反弹里。**

### 2.2 为什么大跌当天开盘不能做

- 集合竞价和开盘前 15～30 分钟，是隔夜情绪的宣泄，不是底部。
- 大跌后低开，经常还有二次下探；开盘那一笔买在「今天最低」的概率很低。
- 你无法在开盘瞬间分清：这是恐慌结束，还是下跌中继。
- 真正的底部，至少需要时间换空间：跌势变缓、抛压变轻、不再创新低，而不是「已经跌了很多所以该涨了」。

### 2.3 什么叫「真正出现了底部」（再允许动手）

不必一次凑齐，但至少要看到**盘中或隔日**的确认，而不是开盘那一下：

- 不再连续快速创新低，低点开始抬或走平
- 下跌放量之后，后续阴线**缩量**，抛压衰竭
- 分时上探底回升，且回升能站住，而不是抽一下再砸
- 同板块龙头先稳住，个股不再单独补跌
- 更稳妥：至少观察到一根有意义的止跌 K 线收盘后再考虑，而不是早上 9:30 下单

底部是**看出来的**，不是猜出来的。没看清就继续等。

### 2.4 「能直接涨起来」的前提：前一天也在涨

这条是用来过滤「今天会不会开盘就拉」的：

| 前一日状态 | 次日开盘策略 | 原因 |
|:-----------|:-------------|:-----|
| 前一日收阳、趋势向上、资金仍在 | 可以按计划参与强势延续（高开、顺势） | 短线惯性还在，直接拉升更常见 |
| 前一日大跌、放量阴、恐慌抛售 | **开盘不做**，等底部 | 惯性向下，开盘买的是情绪，不是趋势 |
| 前一日平盘或小阴小阳、方向不明 | 开盘观望，等分时和板块给出方向 | 没有「直接涨」的前提 |

所以：

- **顺势票**：昨涨 → 今强，才谈得上开盘附近动手。
- **超跌票**：昨跌 → 今低开，一律当作未完成的下跌，直到底部信号出现。

不要把规则一的「半导体出货后切银行」理解成「大跌的半导体开盘抄回来」。规则一是**离开出货板块**；规则二是**大跌标的禁止开盘接**。两者不冲突。

### 2.5 执行节奏

| 情景 | 开盘 | 盘中 | 收盘后 |
|:-----|:-----|:-----|:-------|
| 持仓股大跌 | 不补仓、不摊低 | 只减不加，直到止跌 | 复盘是否进入底部观察名单 |
| 想抄的票大跌 | 不买 | 只看不碰 | 列入观察，等底部信号 |
| 昨涨今强的票 | 可按计划跟 | 弱转强再加，强转弱减 | 记录是否仍满足「昨涨」前提 |
| 半导体昨夜抛压 | 执行规则一：清仓切换 | 不因盘中反抽改计划 | 检查轮动是否完成 |

## 规则三：抛出尽量在日内均线上方，不要在均线下方卖

### 3.1 核心动作

做短线时，**卖出要尽可能发生在日内均线上面**，而不是在均线下方把股票抛掉。

这里的「日内均线」优先看**分时图上的均价线**（黄线 / 分时均价）。它就是当天买家的平均成本：

- 价格在均线**上方**：当天买的人整体还赚钱，盘面偏强，抛单更容易有人接。
- 价格在均线**下方**：当天买的人整体被套，抛压更重，这时候卖，卖的是最差的一段。

一句话：

> **能卖在均线上面，就不要卖在均线下面。**
> 均线下方是弱势区，不是你该交枪的地方。

### 3.2 怎么执行

| 价格位置 | 卖出纪律 | 买入纪律 |
|:---------|:---------|:---------|
| 分时均价线上方 | 可以按计划减仓、兑现；这是正常抛出区 | 可以考虑跟，仍要满足规则二（昨涨、非大跌开盘） |
| 刚好回踩均价线、能站住 | 优先在这里减，不必等最高点 | 强势回踩可观察，站住再考虑，跌破就放弃 |
| 分时均价线下方 | **尽量不主动砸盘卖出**；等反抽到均线附近再走 | **默认不买**。均线下面接，等于在日内成本下方接飞刀 |

实操顺序：

1. 想卖的时候，先看现价在不在分时均价之上。在上面，可以卖。
2. 如果已经跌破均价，先别市价往下砸。给它一次回到均线的机会，回到均线附近再把该减的减掉。
3. 反抽回均线后如果仍走弱、再次跌破，那一次回抽就是最后的卖点，不要再等下一次。
4. 买也尽量买在均线上方。均线下方的「便宜」，短线里多半是陷阱，不是折扣。

### 3.3 为什么不能在均线下方抛

- 均线下方卖，成交价通常更差，等于用最差的价格结束交易。
- 下面抛会进一步打压均价，自己给自己制造更差的出场。
- 短线的利润本来就薄，卖点差一截，一笔好票也会变成「白做」。
- 买在均线上方、卖也在均线上方，才是同一套强弱逻辑；买强卖弱是最常见的自我消耗。

### 3.4 和前面规则怎么共用

- **规则一（半导体必须清仓）** 属于风控优先：板块已经在出货，可以接受次优价格先出来。能碰到反抽到均线再走更好，但不要为了「等均线」把该清的仓又拿回去。
- **规则二（大跌等底）** 与本条一致：大跌后价格往往就在均线下方，开盘更不要买，也不要在下面补仓。
- **规则四（开盘先走一半）** 是隔夜浮盈的固定动作，开盘那半仓先执行；**剩下的半仓**再按本条，尽量在均线上方卖。

### 3.5 这条规则的边界

- 尾盘马上收盘、明显跌破均价且回抽无望，可以按计划减，不必为了均线硬拿到第二天——那是把规则三做成了扛单。
- 涨停板里封死，不是「均线上方还要再等更高」；该锁的利润用规则四处理。
- 均线被反复刺穿、价格贴着均价磨，说明当天方向不清，减仓优先于纠结精确卖点。

## 规则四：第二天开盘赚钱，必须先抛 1/2，剩下才允许继续跑

### 4.1 核心动作

短线单子如果**第二天开盘已经赚钱**（开盘价高于成本，出现浮盈）：

1. **开盘就抛出 1/2 仓位**，先把一半利润锁住。
2. **只留剩下 1/2 继续奔跑**，让利润跟随剩余仓位走。
3. **禁止把全部仓位都留下来继续跑。** 全仓奔跑 = 把已经出现的收益重新交给市场。

这样做的目的很明确：**既保留收益，也减少风险。** 一半落袋，一半跟趋势，不是「看对了就要拿满」。

### 4.2 触发条件（什么叫「开盘赚钱」）

满足再执行，没赚钱不要机械砍一半：

- 以**开盘价（或开盘可成交价）对比持仓成本**，已经是浮盈。
- 典型情况：昨买今高开、跳空、竞价就在成本之上。
- 开盘只是平盘或微亏，**本条不强制卖一半**；改看规则二、规则三，该等底等底，该等均线等均线。
- 开盘大幅低开、浮盈消失甚至变亏：按规则二处理，开盘不补仓；要减也尽量等反抽，不要在最恐慌的第一笔里把全部希望砸掉。

### 4.3 执行节奏

| 时点 | 动作 |
|:-----|:-----|
| 集合竞价 | 确认：开盘价是否已经高于成本。是 → 挂出 1/2 减仓，开盘就走 |
| 开盘 0～15 分钟 | **先完成那 1/2**，不要等「再冲一波再卖一半」。规则四的卖点就是开盘，不是盘中高点 |
| 留下的 1/2 | 允许继续跑。卖点改走规则三：尽量在分时均价上方减、在均价下方少砸 |
| 留下的 1/2 冲高再回落 | 冲高可继续减；跌破均价且回抽失败，剩余仓位也要收，不要又变回全仓幻想 |
| 留下的 1/2 继续大涨 | 可以拿，但仍是半仓在跑，禁止因为涨得好又把卖掉的一半买回来追 |

仓位拆法尽量简单：100% 持仓 → 开盘卖掉一半 → 剩余一半跟。不要临时改成卖 1/3、卖 1/4。短线纪律靠固定比例，不靠盘中感觉。

### 4.4 为什么必须开盘走一半，而不是全仓继续跑

- 隔夜赚钱，说明这笔短线已经被市场证明过一次。先走一半，是把「正确」兑现成现金。
- 开盘往往是隔夜情绪最集中的位置：高开不走，后面经常回吐；等高点再卖一半，那一半经常就卖不到了。
- 全仓奔跑时，一次回撤就能把隔夜利润吐干净，心理上又会从「拿利润」变成「等回本」，最容易拿成隔夜变隔周。
- 半仓留下，涨了你还在车上；跌了你已经锁了一半。这是收益和风险同时处理，不是二选一。

### 4.5 和前面规则怎么共用

```
昨买今开
    │
    ├─ 开盘已经赚钱？ ──是──→ 开盘立刻卖 1/2（规则四，优先执行）
    │                         剩余 1/2：尽量在日内均线上方继续兑现（规则三）
    │
    ├─ 开盘没赚钱 / 低开？ ──→ 不强制卖一半
    │                         大跌则开盘不做、不补（规则二）
    │                         要卖尽量等回到均线附近（规则三）
    │
    └─ 若是半导体昨夜抛压 / 科技暴击 ──→ 规则一、规则五优先：该清的科技仓先清
                                          清仓目标优先于「留一半奔跑」
```

- 规则四管的是**已经盈利的短线隔夜仓**，不管新开仓、不管大跌抄底。
- 留下的那一半，仍然要服从规则三，不是「既然留了就可以无限拿」。
- 规则一、规则五的「必须离开科技」如果和「留一半奔跑」冲突，**听清仓纪律**：出货板块没有资格用半仓去赌继续跑。

## 规则五：市场暴击、科技股大规模下跌时，切向银行与资源防守名单

### 5.1 核心动作

当股市迎来**暴击**，同时**科技股出现大规模下跌**时：

1. **不要去抄科技、半导体、高位成长。** 暴击日的科技低开，不是便宜，是规则二里的开盘陷阱。
2. 把注意力转到下面这份轮动观察名单，看谁还接得住钱：
   - **银行股（首选，最好买这里）**
   - 航运港口
   - 焦炭
   - 煤炭开采
   - 军工电子
   - 房地产
   - 贵金属
3. 名单里也不是一起买完。先看银行；银行如果当天也能承接，就以银行为主。其余板块只买**相对抗跌、有资金进、分时在均线上方**的，不买跟着科技一起砸的。

一句话：

> **科技暴击日：科技只出不进。**
> **转头看银行，以及航运港口、焦炭、煤炭、军工电子、地产、贵金属。**
> **最好是银行股。**

### 5.2 什么叫「暴击 + 科技大规模下跌」

要同时看到市场和科技两边，而不是单票阴跌就启动：

- 指数（上证 / 创业板 / 科创）出现明显暴跌、跳空或盘中加速杀跌，情绪是「打暴击」而不是普通调整
- 科技方向（半导体、AI、消费电子、软件等）**板块性**下跌，龙头与中军一起走，成交放大
- 不是一两只科技票的独立利空，而是成长风格整体被砸
- 同一日银行、红利、资源、高股息相对抗跌，或已经有资金从科技里出来

半导体单独放量出货、大盘还没暴击时，仍先走**规则一**（清半导体 → 大行 / 股份行 / 春分动力）。本条是更大一级：市场被打、科技整片在跌，轮动名单扩开。

### 5.3 观察名单怎么用（有顺序，不是平均买）

| 优先级 | 方向 | 用法 |
|:------|:-----|:-----|
| 1（最好） | **银行** | 暴击日资金最常先去的地方。大行稳、股份行弹性略大。能买银行就不必强行铺开所有板块 |
| 2 | 航运港口、焦炭、煤炭开采 | 偏资源和周期，科技杀估值时，部分资金会切到「有现金、有商品属性」的方向 |
| 3 | 贵金属、房地产 | 避险 / 政策博弈型承接。要看当天是否真有资金，没有承接就只观察 |
| 4 | 军工电子 | 在名单里，但名字带「电子」。**只有它不跟科技一起砸、能独立走时才看**；若军工电子也在崩，直接划掉，改回银行和煤焦、港口 |

执行时只做三件事：科技仓尽快降下来；打开这份名单看谁抗跌；**银行能接就先银行。**

### 5.4 执行节奏

| 时点 | 动作 |
|:-----|:-----|
| 暴击当天开盘 | 科技方向：**开盘不买、不补**（规则二）。已有科技仓，能减则减，反抽到均线再减更好（规则三） |
| 开盘后观察 | 先看银行是否抗跌、是否有买盘。再扫一眼港口、煤焦、贵金属、地产、军工电子谁没跟跌 |
| 盘中 | 只允许买名单里走强或明显承接的方向；禁止因为「科技已经跌很多了」而买回来 |
| 收盘后 | 确认科技是否仍在大规模出货。是 → 次日继续远离科技，轮动以银行为主 |

### 5.5 和规则一、规则二的关系

- **规则一**是窄口径：主流半导体昨夜大量抛单 → 清半导体，看银行和春分动力。
- **规则五**是宽口径：大盘暴击 + 科技整片大跌 → 清科技，看银行（最好）以及港口、焦炭、煤炭、军工电子、地产、贵金属。
- 两天信号叠在一起时，**银行是公共首选**，两套名单可以合并看，但仓位不要铺成「每个板块买一点」。
- 无论切到名单里哪一个，买入仍要服从规则二：暴击当天开盘不做；能直接涨的，前提是它前一天已经在涨，或者当天已经确认承接、站上日内均线。
- 切过去之后，隔夜若已赚钱，次日开盘仍走规则四：先抛 1/2。

### 5.6 这条规则的边界

- 科技只是轮动、指数没有暴击，不要把煤焦地产贵金属全部当必买；先看规则一够不够用。
- 名单里某个板块当天也在暴跌，就从当天的可买列表里删掉，**尤其是军工电子跟着科技砸的时候**。
- 「关注购买」不等于开盘扫货。先确认承接，再买；买了也按规则三、规则四管卖点。
- 最好是银行：银行接不住时，可以空仓或只做名单里真正有资金的那一条，不必为了轮动而买齐六个方向。

## 规则六：次日热点预判与隔夜埋伏

### 6.1 核心动作

没法稳定算准「明天哪个题材最热」。能提高胜率的，是识别**今天已经启动、但还没走完**的方向，用小仓隔夜等确认；不是收盘后凭感觉猜一个全新题材，再打满去埋伏。

收盘后只做三件事：

1. **定主线处于哪一段**（启动 / 发酵 / 高潮 / 退潮），从而判断明天是延续、补涨，还是切换。
2. **只把「今天已经在涨」的方向列入隔夜观察**；今天收阴、放量杀、缺口向下的，一律不隔夜。
3. **隔夜仓必须小。** 次日集合竞价是确认开关：强开按计划留；弱开、低开、板块集体软，埋伏失败，开盘按计划处理，不要等盘中「再给你一次机会」。

一句话：

> **前一天埋伏的是概率方向，第二天竞价才是确认。**
> **没确认之前，仓位必须小到「错了也伤不了」。**

这和总原则第 1 条、规则二是同一套逻辑：先看板块资金；能直接涨的票，昨天也得在涨。

### 6.2 明天热点通常只有三种，不是无限可能

| 今天主线状态 | 判断要点 | 明天更可能发生什么 | 能不能隔夜埋伏 |
|:-------------|:---------|:-------------------|:---------------|
| **启动** | 刚扩散、龙头才首板/二板、跟风还不多 | 主线延续 | 可以。埋伏中军/补涨，不追最高位 |
| **发酵** | 梯队成形、赚钱效应好 | 主线内部轮动：龙头分歧，补涨启动 | 可以埋伏「今天没涨停但已经在涨」的补涨 |
| **高潮** | 高度板、全市场都知道 | 分歧、高开低走 | **不隔夜扛龙头** |
| **退潮** | 龙头断板、跟风大面积破板 | 主线切换 | 按规则一、规则五找承接，不抄今天被砸的 |

短线里「第二天的热点」，十次有七八次不是新故事，而是：

1. **今天主线的延续**
2. **同一主线里还没涨的补涨**
3. **今天出货板块吐出来的钱，流到昨天已经抗跌的方向**

第三种已经由规则一、规则五覆盖：半导体抛压 → 银行；科技暴击 → 银行 / 港口 / 煤焦。规则六不管「切换去哪份名单」，只管：**什么时候允许隔夜、埋伏谁、仓位多大、竞价怎么确认。**

### 6.3 前一天怎么判断（收盘后四步）

#### 第一步：先量市场温度，再谈题材

温度不对，题材再好听也不埋伏。看这几项就够：

- 涨停家数是增加还是减少
- 最高板还在不在、连板晋级率高不高
- 破板多不多（亏钱效应）
- 今天赚钱的人，主要赚在哪个板块

**温度热**：可以埋伏延续或补涨。  
**温度冷 / 高潮后大面积破板**：不埋伏进攻题材，只执行「这边在出、那边接得住」的切换；接不住就空仓。

#### 第二步：找出今天真正的主线

主线不是朋友圈聊得最多的，而是同时满足：

- 板块里涨停最集中
- 板块资金是净流入，不是假拉
- 有辨识度的龙头（不是一盘散沙各涨各的）
- 尾盘没有被集中砸掉

总原则已经写了：前一交易日主流板块的抛压，往往比当天开盘的情绪更提前。反过来也成立——前一天下午还在被抢的方向，第二天高开的概率更高。

#### 第三步：看主线有没有「余粮」

有余粮，明天还能炒；没余粮，明天大概率切走。

- **有余粮**：同题材里还有低位、没涨停、但今天已经翻红走强的中军
- **没余粮**：龙头在高位、跟风都涨过一轮、剩下的都是杂毛
- **切换信号**：龙头放量滞涨或断板，同时另一个板块尾盘突然有资金、抗跌甚至翻红

切换时不要猜「下一个风口会是什么新概念」。就看：**今天谁在出、谁已经接得住。** 接不住，按纪律空仓，不为了有仓位而买。

#### 第四步：今晚只扫描「催化」，不扫描「故事」

隔夜新闻的正确用法是：**确认已经在走的方向**，不是凭一篇稿子去开全新仓。

- 有用的催化：政策/会议、行业事件、商品价格、业绩预告、明确的板块利好
- 没用的催化：没有资金、今天也没涨、纯靠想象的新名词

催化 + 今天已经在涨 → 可以列入明天观察。  
只有催化、今天还在跌 → 按规则二，开盘不做。

### 6.4 尾盘 30 分钟是含金量最高的时段

短线里，**14:30–15:00** 比早上任何技术指标都更接近次日方向。前一天埋伏真正该做的时间，往往是**尾盘确认之后**，而不是上午脑子一热提前锁仓。

| 尾盘现象 | 对明天的含义 | 埋伏动作 |
|:---------|:-------------|:---------|
| 板块尾盘抢筹、回封、中军翻红 | 明天高开、情绪延续 | 可小仓埋伏补涨/中军 |
| 龙头尾盘炸板、板块跟风一起砸 | 明天低开、主线分歧或退潮 | 不隔夜，次日看承接 |
| 主线砸、另一个方向尾盘突然拉起来 | 切换可能已经开始 | 只观察「今天已经在涨」的承接方向 |
| 尾盘无量阴跌、一盘死水 | 明天大概率没主线 | 不埋伏 |

### 6.5 三种埋伏，只做一种

#### A. 埋伏延续（最常见，也最符合规则二）

条件同时满足：

- 今天这个方向**已经在涨**
- 还没高潮（不是最高板、不是全民共识）
- 尾盘不砸
- 同板块还有没涨透的中军

埋伏谁：**龙二、中军、低位补涨**，不是今天最猛的那只龙头。龙头隔夜最容易高开低走。

#### B. 埋伏补涨（发酵期更好用）

今天龙头已经很贵或出现分歧，但板块没死、跟风还没走完。明天资金会去「同逻辑、今天没涨停、分时却强」的票。

补涨的前提是主线还活着。主线已经退潮，就没有补涨，只有轮流砸。

#### C. 埋伏切换（规则一、规则五已经覆盖方向）

只有「这边明确在出、那边今天已经抗跌或尾盘有资金」才做。  
半导体昨夜抛压 → 银行；科技暴击 → 先看银行。  
**禁止**埋伏今天大跌的科技去做超跌反弹——那是规则二明确禁止的开盘陷阱。

三种埋伏同一天只选一种。既想扛主线龙头、又想打补涨、又想切银行，等于没有计划。

### 6.6 执行节奏

| 时点 | 动作 |
|:-----|:-----|
| 14:30 前 | 可以观察、列名单，**默认不提前锁隔夜仓**。上午的强不等于尾盘还强。10:40 之后到 14:40 按规则七：**只卖不买** |
| 14:30–14:40 | 开始确认尾盘是抢筹还是砸盘；仍只观察，不锁隔夜、不开新仓 |
| 14:40–15:00 | 规则七的尾盘买入窗。确认主线是抢筹还是砸盘；有无新方向尾盘异动；余粮还在不在。**只有这里才允许买、才允许锁隔夜小仓** |
| 收盘后 | 走完 6.3 的四步；写出：明天三种可能里选哪一种、埋伏哪几只、仓位上限、竞价弱开怎么处理 |
| 隔夜 / 盘前新闻 | 只用来确认已有方向。新闻把你推向「今天没涨的新故事」，直接划掉 |
| 次日集合竞价 | **确认开关**。板块强开、标的在成本之上 → 按规则四：开盘先走 1/2，留 1/2。弱开、低开、板块软 → 埋伏失败，开盘处理，不扛 |
| 开盘 0～15 分钟 | 先完成「赚钱走一半」或「失败离场」，不要等盘中再给你一次机会 |
| 留下的仓位 | 改走规则三：尽量在分时均价上方减；均价下方不接飞刀、少砸 |

仓位纪律尽量简单：隔夜埋伏是**观察仓，不是主仓**。不要因为「看对了方向」就把隔夜仓打满——打满隔夜，等于把不确定的「可能」当成已经发生。

### 6.7 和前面规则怎么共用

```
收盘后预判次日热点
    │
    ├─ 温度冷 / 高潮后退潮 / 大面积破板？
    │         ──是──→ 不埋伏进攻题材
    │                  改走规则一、规则五：谁在出、谁接得住
    │                  接不住 → 空仓
    │
    ├─ 主线仍在启动或发酵，且今天已经在涨？
    │         ──是──→ 小仓埋伏延续或补涨（规则六）
    │                  埋伏龙二/中军/低位补涨，不隔夜扛最高位龙头
    │
    ├─ 想埋伏的票今天在跌、放量杀、缺口向下？
    │         ──是──→ 禁止隔夜（规则二）
    │                  开盘也不做，等底部
    │
    └─ 只有新闻故事、今天并没有资金？
              ──是──→ 不开仓。催化不能代替「昨涨」

次日开盘
    │
    ├─ 竞价弱开 / 板块软？ ──→ 埋伏失败，按计划处理，不扛
    │
    ├─ 开盘已经赚钱？ ──→ 规则四优先：开盘先抛 1/2
    │                      剩余 1/2 走规则三（均线上方兑现）
    │
    └─ 若同时触发规则一 / 规则五（科技必须离开）
                              ──→ 清仓纪律优先于「留一半奔跑」
```

- 规则二管的是**谁有资格被埋伏**：没有昨涨，就没有隔夜。
- 规则四管的是**埋伏对了以后怎么活**：隔夜赚钱必须先走一半，说明隔夜仓本身就是高不确定性头寸。
- 规则三管的是**留下那一半怎么卖**：尽量卖在分时均价上方。
- 规则一、规则五管的是**退潮以后切去哪**：规则六不另起一份进攻名单。
- 规则一、规则五的「必须离开科技」如果和「隔夜留一半」冲突，**听清仓纪律**。

### 6.8 这条规则的边界

- 预判错是常态。规则六的价值不在「猜中题材」，而在**限制你只能小仓、只埋伏昨涨、必须用竞价确认**。
- 高潮期的龙头可以盘中看，不可以隔夜扛。高开低走是这个位置的常见收场。
- 尾盘没确认，不要因为上午强、盘中强，就提前当成隔夜票。
- 切换失败（承接方向今天也没涨、也没抗跌）时，空仓。不为了「明天总得有热点」而买。
- 同一天三种埋伏只做一种；名单不超过自己能盯住的几只，禁止铺成「每个可能热点买一点」。

## 规则七：两个强烈买入点——10:40 之前、14:40 之后；中间只卖不买

### 7.1 核心动作

短线买入只允许落在两个时间窗里：

1. **上午 10:40 之前**（含开盘后到 10:40）
2. **下午 14:40 之后**（到 15:00 收盘）

**10:40 到 14:40 之间：只卖不买。** 可以减仓、兑现、按规则四走一半、按规则三等均线回抽再卖；禁止开新仓、禁止补仓、禁止「盘中看起来又强了」再买回来。

一句话：

> **买只买两头，中间只出货。**
> 10:40 前确认早盘方向；14:40 后确认尾盘真假。中间那段最会骗人。

### 7.2 为什么是这两个点，而不是全天随便买

A 股短线的钱，集中出现在早盘定方向、尾盘定隔夜。中间两三个小时，更多是回吐、假突破、午后诱多。

| 时段 | 市场在干什么 | 你只能干什么 |
|:-----|:-------------|:-------------|
| 9:30–10:40 | 隔夜单子兑现、主线是延续还是骗炮，通常在这段里见分晓 | **允许买**（仍要过规则二、三、六的过滤） |
| 10:40–11:30 | 早盘脉冲结束，开始磨、回吐、假方向 | **只卖不买** |
| 11:30–13:00 | 午休，没有新信息 | 不交易 |
| 13:00–14:40 | 午后最容易出现「拉一下又砸」「补涨一下就没了」 | **只卖不买** |
| 14:40–15:00 | 尾盘抢筹还是砸盘，接近次日方向（与规则六同一时段） | **允许买**（更适合确认后的隔夜/尾盘） |

10:40、14:40 是硬截止，不要改成「再等 5 分钟、这根看起来要突破」。错过就错过，下一窗再看。

### 7.3 两个买入窗分别怎么用

**窗 A：10:40 之前（早盘窗）**

- 用来做**当天已经能看清的顺势**：昨涨今强、竞价确认、分时站上均价、板块同步。
- 不是「9:30 一开盘就必须买」。开盘几分钟仍然可以先看；规则四该卖的一半，开盘先卖掉。
- 大跌日、暴击日：规则二优先，**开盘不做**。若到 10:40 仍未见底部、仍在均线下方，这个早盘窗直接作废，不要因为「窗口要关了」而抢买。
- 10:40 一到，手里没有买到，就停。不要在 10:41 追那一下。

**窗 B：14:40 之后（尾盘窗）**

- 用来做**尾盘确认后的买入或隔夜小仓**，和规则六同一逻辑：14:30 可以开始观察，**14:40 之后才允许买、才允许锁隔夜**。
- 尾盘抢筹、回封、中军翻红，才考虑买；尾盘砸盘、无量阴跌，这个窗口也作废。
- 这里买的是「今天已经在涨、尾盘还被要」的方向，不是下午才突然拉起来、均线都没站稳的票。
- 14:40 后买了，仍是观察仓：次日开盘赚钱走 1/2（规则四），弱开按计划处理（规则六）。

### 7.4 中间「只卖不买」怎么执行

10:40–14:40 允许的动作：

- 规则四没走完的减仓，补走
- 冲高后在分时均价上方兑现（规则三）
- 跌破均价、回抽失败后的离场
- 科技/半导体触发规则一、规则五时的清仓（风控优先，中间也可以卖）

中间禁止的动作：

- 开新仓、补仓、摊低
- 卖飞了再买回来
- 「午后好像又启动了」追进去——这类启动，等到 14:40 还在，再买不迟；撑不到 14:40 的，本来就不该买

### 7.5 和前面规则怎么共用

```
想买的时候，先看表
    │
    ├─ 现在是 10:40–14:40？ ──是──→ 不准买，只卖
    │
    ├─ 现在是 10:40 之前？ ──→ 早盘窗：可以买
    │                         仍须：昨涨 / 非大跌开盘硬抄（规则二）
    │                         分时尽量在均线上方（规则三）
    │                         该卖的一半开盘先卖掉（规则四）
    │                         暴击日不买科技（规则五）
    │
    └─ 现在是 14:40 之后？ ──→ 尾盘窗：可以买 / 可以锁隔夜小仓
                              先观察尾盘是抢筹还是砸盘（规则六）
                              只买今天已经在涨、尾盘还在的方向
                              仓位必须小
```

- 规则七管的是**什么时间允许按买入键**，不管买哪个板块。
- 规则二管的是**即使在买入窗里，大跌开盘也不能买**。窗口是资格，不是命令。
- 规则六的「尾盘确认后才隔夜」，收口到 14:40 之后；14:30–14:40 继续观察，仍只卖不买。
- 卖出不受这两个窗口限制：该减就减，开盘可以卖，中间可以卖，尾盘也可以卖。

### 7.6 这条规则的边界

- 涨停排队、一字板不是「中间破例去追」。买不到就等下一窗或放弃。
- 规则一、规则五的清仓，任何时间都可以卖，不必等到买入窗。
- 早盘窗里没看清，不要用「窗口马上关闭」当买入理由。看不清 = 这窗不做。
- 尾盘窗只剩十几分钟，更要小仓、更要确认，不要 14:55 还在追高打满。

## 规则八：开盘急转直下时，克服「立刻卖掉」的冲动

### 8.1 核心动作

开盘后走势**急转直下**（高开转绿、直线跳水、分时瀑布），这时最想按卖出的，通常也是**当天最差的价格**。你已经知道这个价不好，还是想卖——要克服的不是「该不该走」，而是「现在这一秒该不该砸」。

拆成两步，冲动才压得住：

1. **决定可以立刻做**：这笔要减、要走、不再加仓。方向可以马上定。
2. **下单必须等一等**：不在瀑布最陡的地方市价砸。等第一段急跌停住，或价格回到分时均价附近，再把该卖的卖掉。

一句话：

> **急转直下时，第一反应是停手，不是下单。**
> 你害怕的是继续跌；你亏更多的，往往是在最差价格把自己交出去。

### 8.2 为什么这时候最想卖，偏偏最不该砸

- 开盘急杀是全市场一起宣泄，你的对手盘也在砸。你卖得越急，成交越差。
- 分时均价还来不及下来，现价已经掉到均线下面——这正是规则三说的弱势区。在这里卖，是主动选最差一段。
- 「立刻卖掉才能安心」是情绪，不是计划。计划里的卖点是均线上方或回抽；情绪里的卖点是眼前这根阴线。
- 规则四已经要求：开盘赚钱先走 1/2。那一半如果开盘价还好，应该在急转**之前**或开盘那一下就走完。急转之后还想把剩下的一半也砸掉，等于把「留一半奔跑」临时改成「恐慌清仓」。

### 8.3 克服冲动的固定动作（先做这些，再碰键盘）

手已经要按卖出时，强制走完下面这一遍，不许跳过：

| 问自己 | 答「是」就停手 | 然后怎么做 |
|:-------|:---------------|:-----------|
| 我是因为害怕才卖，还是因为盘前计划就要卖？ | 只是害怕 | 停手。计划没写「瀑布里市价清仓」 |
| 现价在不在分时均价下方？ | 在下方 | 不准砸。等回到均线附近再卖（规则三） |
| 这是不是最陡的那一段（几乎没有下影、直线掉）？ | 是 | 再等。至少等到第一段停住、出现一次回抽 |
| 规则四该走的 1/2，开盘价还好的时候走了没有？ | 还没走，但现在已经瀑布 | 也不要在最差价补走全部；先等回抽，回抽时再走计划中的一半 |
| 是不是半导体/科技必须离开（规则一、规则五）？ | 是，风控优先 | 可以走，但仍尽量卖在回抽上，不要叠加恐慌盘一起砸 |

**最小执行纪律（写死）：**

1. 看到急转直下，**双手离开键盘 3 分钟**，或等到 9:35 之后，以较晚者为准。这 3 分钟只看：跌势有没有停、有没有第一下回抽、现价和均价的距离。
2. 3 分钟内只允许做一件事：**不加仓、不补仓、不新开**（规则二、规则七）。卖出单先挂在脑子里，不挂在最差价上。
3. 出现第一次明显回抽（向均价靠近、或急跌后的第一根像样阳分时），这才是你的卖点。回抽时卖，是「知道价不好之后，去找一个没那么差的价」。
4. 回抽后再跌破、均线也站不回去，那一次回抽就是最后卖点，不要幻想还有第二次更好的。这不是扛单，是把恐慌卖点换成回抽卖点。

### 8.4 几种常见盘面，分别怎么处理

| 开盘情形 | 冲动会让你做什么 | 纪律让你做什么 |
|:---------|:-----------------|:---------------|
| 开盘仍赚钱，随后急转直下 | 全部砸掉，生怕利润吐光 | 开盘价还好时先走 1/2（规则四）；剩下 1/2 等回抽到均线再减，禁止瀑布里清完 |
| 平开后突然跳水 | 立刻市价逃 | 停 3 分钟。跳水中途不卖；第一下回抽再按计划减 |
| 低开且开盘价已经不好，再急杀 | 开盘就清仓，求一个「卖出去了」 | 开盘价本身就差，更不要在更差的地方加一刀。等停住/回抽；大跌开盘也不准买回来（规则二） |
| 隔夜埋伏弱开 + 急转 | 觉得埋伏错了，不计成本离场 | 弱开可以按规则六「失败离场」，但离场点仍尽量等回抽，不要把「失败」执行成「砸在地板上」 |
| 科技/半导体暴击必须离开 | 和别人一起砸 | 方向对（必须走），价格仍要挑。能等 3 分钟和第一下回抽，就不要选瀑布最深处 |

### 8.5 用仓位设计，减少「必须立刻卖」的心理

冲动之所以压不住，常常是仓位太大：全仓看着瀑布，不卖就觉得要没了。

- 隔夜本来就只能小仓（规则六）。仓位小，才等得起 3 分钟和一次回抽。
- 开盘赚钱必须先走 1/2（规则四）。一半已经落袋，剩下那一半才有资格「不怕、等更好的卖点」。
- 若你发现自己一急转就想全卖，说明隔夜仓或早盘仓已经超标——当天先按纪律处理，收盘后把仓位降到「等 3 分钟也不会崩溃」的水平。

克服冲动靠的是**提前拆仓 + 临时停手**，不是靠盘中给自己打气。

### 8.6 和前面规则怎么共用

```
开盘急转直下
    │
    ├─ 第一反应 ──→ 停手 3 分钟（或等到 9:35），不市价砸
    │
    ├─ 开盘价曾经赚钱？ ──→ 那一半应在急转前/开盘走掉（规则四）
    │                         没走也别在瀑布里把另一半一起砸完
    │
    ├─ 现价在分时均价下方？ ──→ 不准砸（规则三）
    │                            等第一下回抽到均线附近再卖
    │
    ├─ 是必须离开的科技/半导体？ ──→ 方向：走（规则一、规则五）
    │                                价格：仍等回抽，不选最差一笔
    │
    └─ 回抽出现后仍弱、再次跌破 ──→ 那次回抽就是最后卖点
                                    卖完不再买回来（规则二、规则七）
```

- 规则三回答「卖在哪」：均线上方，不在下方砸。
- 规则八回答「急转时手痒怎么办」：先停手，等回抽，把情绪卖点换成价格卖点。
- 规则四的开盘走 1/2，指的是**开盘价还过得去的时候**先锁一半；不是授权你在急杀最深处把全部卖掉。
- 规则一、规则五可以逼你「必须离开」，但不能授权「必须卖在地板上」。

### 8.7 这条规则的边界

- 停手 3 分钟，不是改成扛整天。回抽来了要卖；尾盘仍无回抽、均线回不去，按规则三的边界处理，不要为了「等好价格」拿到第二天再挨一刀。
- 预埋的止损如果是隔夜计划里写死的，按计划执行；但计划不应写成「开盘急杀就市价全砸」。计划应写成：「弱开/急转 → 等第一回抽减仓」。
- 克服冲动 ≠ 假装没跌。不加仓、不摊低、不讲故事。你只是拒绝在最差的价格成交。
- 若 3 分钟后已经接近跌停、没有回抽空间，这是极端流动性问题：能减一点算一点，但那是例外，不要每天用「要跌停了」当瀑布里砸盘的借口。

## 规则九：处置效应——截断亏损，让利润奔跑

### 9.1 核心动作

超短线隔日交易追求的是高频率、可执行，不是全盘改策略。真正缺的是**硬性卖出规则**：不能等到第二天盘中凭感觉决定卖不卖。

这笔交易在心理上叫**处置效应（Disposition Effect）**：本能是「截断利润，让亏损奔跑」；交易要活下来，必须反过来——**截断亏损，让利润奔跑**。

盘前就必须写好两类卖出：

1. **成功（股价上涨）**：开盘先走 1/2（规则四）；剩下 1/2 用动态止盈跟着走，直到涨势乏力再出。禁止因为「已经赚到了」把剩下的也提前砍光。
2. **失败（股价下跌）**：触及最大可容忍亏损（默认 **-3%**，上限 **-5%**）必须离场。卖出等于认这笔错了，不是「等它活过来」。

一句话：

> **盈利怕回吐，会把浮动利润锁死；亏损不肯认输，会把风险敞口越放越大。**
> 隔日交易不是策略错了，是卖出还在靠情绪。规则驱动，才能让盈亏比为正。

### 9.2 心理根源（先认清，再谈下单）

| 盘面 | 本能在想什么 | 实际造成什么 |
|:-----|:-------------|:-------------|
| 盈利时 | 害怕到手的利润回吐，急于把浮动盈利变成确定盈利 | 好票被提前截断，利润潜力锁死 |
| 亏损时 | 不愿意承认这笔是错的，卖出等于认输并锁定亏损 | 开始期待反弹，亏损单被「养」大 |

这两种本能叠在一起，盈亏比一定坏：赢的变小，亏的变大。规则四已经管住「全仓把利润赌回去」；规则八已经管住「瀑布里恐慌砸」。本条补的是另一半——**赚了不敢拿、亏了不肯走**。

### 9.3 成功情况：分批锁定 + 动态止盈

不能设一个「涨到某价就全出」的固定目标，然后提前把趋势掐死。隔日框架里，上涨这样处理：

| 步骤 | 动作 | 目的 |
|:-----|:-----|:-----|
| 次日开盘已赚钱 | 按规则四，开盘先抛 1/2 | 把「确定盈利」落袋，对抗损失厌恶 |
| 剩下 1/2 | 继续持有，允许奔跑 | 对抗「截断利润」 |
| 动态止盈 | 从**持有期间日内最高价**回落超过 **3%**（宽松可用 5%）时，卖掉剩余仓位 | 涨的时候一直拿，只有涨势乏力才出 |
| 分时配合 | 剩余仓位仍尽量卖在均线上方（规则三）；急转直下先停手等回抽（规则八） | 动态止盈触发后，也不要选瀑布最差一笔 |

动态止盈是「让利润奔跑」的具体工具：没有固定天花板，只有从高点回落这一条离场线。回落没到 3%，不准因为「怕吐回去」把剩下一半也卖掉。

### 9.4 失败情况：硬性止损（最重要）

每笔隔日交易必须有一个最大可容忍亏损，买入时就写死：

- 默认止损：**成本价 -3%**
- 波动更大、隔夜仓更小的，最多放到 **-5%**，再宽就不是超短线了
- 一旦触及，**无条件离场**。不准改口成「再看一眼」「等回到成本」「已经跌这么多了该反弹了」

硬性止损解决的是处置效应的亏损端：卖出 = 承认这笔错了。不卖 = 让错误继续计息。

和规则八怎么并存：

- **-3% 已经碰到**：交易结论是「错了，必须走」，不是「再扛」。
- **怎么走**：若正撞上开盘瀑布，仍先停手 3 分钟、等第一下回抽再执行止损（规则八管成交价）；回抽之后如果还在止损线下方，立刻出，不准改成等回本。
- **停手不是取消止损。** 3 分钟后没有回抽、价格更差，按止损执行。规则八防止砸在地板上；规则九防止用「等好价格」把亏损扛过隔日。

科技/半导体触发规则一、规则五时，清仓纪律优先于「还没到 -3%」——板块必须离开时，不等止损线。

### 9.5 怎么把规则从脑子里搬到盘上

盘中一靠感觉，处置效应就会回来。用两样东西把卖出变成执行，而不是临场发挥：

1. **条件单 / 预埋单**  
   买入的同时挂好止损条件单（-3% 或你写死的那一档）。第二天即使走神、犹豫、不敢点卖，系统也会在触发后帮你执行。动态止盈也可以按「最高点回落 3%」预埋或开盘后立刻挂上。  
   条件单是纪律的外置开关，不是可选项。

2. **交易日志（每天收盘后必写）**  
   每笔至少记四项：买入理由、盘前写好的卖出信号（止损位、是否开盘走 1/2、剩余仓动态止盈）、实际怎么卖的、有没有被情绪改掉。  
   定期回看，你会看到自己是在「截断利润」还是在「让亏损奔跑」。规则改不改，以日志里反复出现的错误为准，不以当天心情为准。

### 9.6 先让盈亏比为正，再谈胜率

隔日超短线可以高胜率，但系统能不能活，看的是**平均盈利 / 平均亏损**。

- 止损如果是 3%，剩下那一半的奔跑空间，心里至少要按 **6% 以上** 去理解（约 1:2），用动态止盈去实现，而不是再设一个更近的固定止盈把利润砍掉。
- 即便胜率只有 40%，只要平均赢明显大于平均亏，整体仍可以盈利。
- 反过来：胜率再高，若赢的时候只拿一点、亏的时候扛很多，系统一定坏。处置效应就是专门把盈亏比做坏的。

开盘走 1/2 会降低单笔的「全仓利润」，这是故意的：用一半锁确定收益，用另一半去换盈亏比。两半都按「小赚就清」操作，规则四和动态止盈就都废了。

### 9.7 和前面规则怎么共用

```
隔日仓，盘前先写死卖出
    │
    ├─ 次日开盘赚钱？ ──是──→ 开盘走 1/2（规则四，对抗「怕回吐」）
    │                         剩余 1/2：动态止盈
    │                         从日内最高回落 3%（或 5%）再出
    │                         回落未到，不准因害怕而提前砍完
    │
    ├─ 跌到成本 -3%（最多 -5%）？ ──是──→ 硬性止损，必须走
    │                                    瀑布中可等 3 分钟回抽再执行（规则八）
    │                                    回抽后仍在止损下：立刻出，不准等回本
    │
    ├─ 现价在均线下方、但还没到止损？ ──→ 不砸（规则三）
    │                                      也绝不补仓摊低
    │
    └─ 半导体/科技必须离开？ ──→ 规则一、规则五优先于止损线
```

- 规则四管盈利端的第一刀：先锁一半，剩下才允许跑。
- 规则九管盈利端的第二刀：剩下的用动态止盈，直到乏力；并管亏损端：-3% 必须认错。
- 规则八管「止损/减仓时别选最差一笔」；规则九管「不能因为想等好价格就取消止损」。
- 规则三管卖在均线上方；止损触发后，回抽到均线更好，回抽不到也必须走。

### 9.8 这条规则的边界

- 本条优化的是卖出，不是推翻隔日策略。执行不了硬止损和动态止盈，先查纪律，不要先换题材、换指标。
- 隔日交易对开盘专注和执行要求极高。若经常因为情绪放弃规则，问题在执行，不在「缺一个新买点」。
- 若反复确认自己做不好隔日超短线（止损不敢点、盈利拿不住），可以考虑把持有周期调成 **3～5 天波段**，减少开盘随机波动对情绪的放大。那是降级频率，不是放弃「截断亏损、让利润奔跑」。
- 条件单在集合竞价、涨跌停、流动性极端时可能滑点。滑点不是取消止损的理由；成交差，也比死扛强。
- 动态止盈的 3%、止损的 3% 是默认值。要改，只能在复盘后改下一笔的盘前计划，不准盘中把 -3% 改成 -8%。

## 规则十：高开 3% 以上，刚开始就抛一半以上，尽可能快跑

### 10.1 核心动作

当天相对昨收 **高开 3% 及以上** 时：

1. **刚开始就卖掉一半以上仓位**（默认 **2/3**，最少也要超过 1/2）。竞价能出就出，开盘第一笔能出就出，不要等冲更高。
2. 大概率有人在**快速兑换前一天的筹码**：昨天买的人、隔夜埋伏的人，都会把高开放进兑现窗口。你不跑，就是给他们当对手盘。
3. 剩下不到一半，才允许看能不能继续跑。不是全仓留下等「再高开一点」。

一句话：

> **高开 3%，先跑，不是先看。**
> 这是隔夜筹码的兑换价，不是给你加仓的确认价。

### 10.2 为什么 3% 高开要加速跑，而不是按规则四只走一半

规则四是普通浮盈开盘：走 1/2，留 1/2。  
高开 3% 已经不是普通浮盈，更像**情绪一次性定价**：

- 隔夜利润已经提前打进开盘价里，竞价就是昨天持仓者最集中的出口
- 短线里「高开 3% 再一路走高」有，但更常见的是高开后快速回吐、高开低走
- 你若全仓或只象征性减一点，等于把别人的兑现单接下来
- 「尽可能快跑」指的是**仓位先下来**，不是价格已经开始掉了再逃

所以本条是规则四的加强版：门槛从「开盘赚钱」抬到「高开 ≥3%」，减仓从 1/2 抬到 **一半以上**。

| 开盘情况 | 减仓 | 剩下怎么处理 |
|:---------|:-----|:-------------|
| 开盘赚钱，但高开不到 3% | 走 1/2（规则四） | 剩余 1/2 动态止盈（规则九） |
| **高开 ≥3%** | **至少走一半以上，默认 2/3** | 剩余 ≤1/3：能冲就留，冲不动或急转，回抽就清 |
| 高开 ≥3% 且竞价已经大幅放量、封不住 | 能出则出更多，接近清仓也合理 | 不必为了「留一点奔跑」硬留 |

### 10.3 执行节奏

| 时点 | 动作 |
|:-----|:-----|
| 集合竞价 | 看高开幅度是否 ≥3%。是 → 挂出至少一半以上的卖单，优先成交 |
| 开盘 0～几分钟 | **先完成这一大笔减仓**。不要等「再冲 1% 再卖」。本条的卖点就是刚开始 |
| 减完之后 | 剩下的小仓才允许看。分时站上均价、板块还在抢，可以留；否则回抽清掉 |
| 高开后急转直下 | 该走的大头应在急转前已经走掉。没走完的，按规则八：不在瀑布最深处砸剩下那一点，等第一下回抽再清 |
| 别人在冲高开 | **禁止追买。** 高开 3% 是持仓者的跑路窗，不是新开仓的买入窗 |

仓位尽量写死：100% → 开盘卖掉 2/3 → 最多留 1/3。不要盘中改成「这次龙头应该能板，只卖 1/4」。

### 10.4 和前面规则怎么共用

```
次日开盘
    │
    ├─ 高开 ≥3%？ ──是──→ 刚开始就抛一半以上（默认 2/3）
    │                      尽可能快跑，先把隔夜筹码兑出来
    │                      剩下 ≤1/3 才允许看
    │
    ├─ 开盘赚钱但高开不到 3%？ ──→ 规则四：走 1/2，留 1/2
    │
    ├─ 高开后急转、剩下那一点想砸？ ──→ 规则八：大头应已走；
    │                                    剩余不在瀑布里砸，等回抽
    │
    └─ 看到高开 3% 想追进去？ ──→ 禁止。这是兑换窗口，不是买入窗
```

- 规则四是底线：隔夜一赚钱，至少走一半。
- 规则十是加速：高开 3% 以上，走一半已经不够，要走一半以上，尽可能快。
- 规则九的「让利润奔跑」针对的是**减完大头之后剩下的小仓**，不是授权高开 3% 还全仓拿。
- 规则六的高潮龙头本就不该隔夜扛；一旦扛到了高开 3%，本条就是纠错出口。
- 卖出不受规则七买入窗限制：高开 3% 的减仓，开盘就必须做。

### 10.5 这条规则的边界

- 3% 按**相对昨收的开盘涨幅**算，不是相对你成本。成本已经赚 10%、开盘只高开 1%，仍走规则四，不走本条。
- 一字涨停、排板买不进去也卖不出去时，能挂多少挂多少；打开的第一下仍优先减，不要改成「封死了就可以全仓留」。
- 高开 3% 后如果直接封死涨停、全市场抢筹，剩下的 1/3 可以留，但**已经卖掉的一半以上不要买回来追**。
- 本条管的是你已经持有的隔夜/短线仓。没有持仓，看见高开 3% 更不要开新仓。

## 十条规则怎么配合

```
前一日复盘
    │
    ├─ 主流半导体大量抛单？ ──是──→ 次日尽快清仓半导体
    │                                转看：大行 / 股份行 / 春分动力
    │                                （先出来，再看承接，不在半导体上抄）
    │
    ├─ 有没有标的正在大跌？ ──是──→ 开盘不做
    │                                等真正底部
    │                                只有「昨天也在涨」的票，才允许开盘跟强
    │
    ├─ 大盘暴击 + 科技大规模下跌？ ──是──→ 科技只出不进
    │                                      转看：银行（最好）
    │                                      以及航运港口 / 焦炭 / 煤炭开采
    │                                      / 军工电子 / 房地产 / 贵金属
    │                                      （只买有承接的，不买齐）
    │
    └─ 次日热点怎么埋伏？ ──→ 先定主线阶段（启动/发酵/高潮/退潮）
                              只埋伏「今天已经在涨、还没走完」的方向
                              仓位必须小；尾盘确认后才允许隔夜
                              高潮龙头不隔夜，大跌票不隔夜，新故事不隔夜

持仓与卖出
    │
    ├─ 高开 ≥3%？ ──是──→ 刚开始就抛一半以上（默认 2/3），尽可能快跑
    │
    ├─ 第二天开盘已经赚钱（高开不到 3%）？ ──是──→ 开盘先抛 1/2，只留 1/2 跑
    │
    ├─ 隔夜埋伏竞价弱开？ ──是──→ 埋伏失败，开盘按计划处理，不扛
    │
    ├─ 盘中要减仓 / 兑现？ ──→ 尽可能卖在日内均线上方
    │                            不要在均线下方砸
    │
    ├─ 开盘急转直下、想立刻卖掉？ ──→ 先停手 3 分钟
    │                                不在瀑布里砸
    │                                等第一下回抽 / 回到均线再卖
    │
    ├─ 这笔隔日仓盘前卖出写死了吗？ ──→ 赚：开盘 1/2 + 剩余动态止盈（最高点回落 3%）
    │                                  亏：-3%（最多 -5%）硬止损，不准等回本
    │
    └─ 现在几点？ ──→ 10:40 前或 14:40 后：才允许买，如果出现高价格可以考虑抛出
                      10:40–14:40：只卖不买
```

- 规则一解决的是：**半导体已经在出货，你还停在里面。**
- 规则二解决的是：**已经大跌了，你还想在开盘那一下买回来。**
- 规则三解决的是：**该卖的时候卖在最弱的位置，把价格主动做差。**
- 规则四解决的是：**隔夜已经赚到了，却把全部仓位继续押上去。**
- 规则五解决的是：**市场暴击、科技整片在跌，你还想抄科技，或者轮动没有方向。**
- 规则六解决的是：**想做次日热点，却去猜全新题材、隔夜扛龙头、或把隔夜仓打满。**
- 规则七解决的是：**全天都想买，尤其在最容易假突破的午市中间下手。**
- 规则八解决的是：**开盘一急转，明知道价不好，还是忍不住砸在地板上。**
- 规则九解决的是：**赚了怕回吐提前砍光，亏了不肯认错死扛——处置效应把盈亏比做坏。**
- 规则十解决的是：**高开 3% 了还当普通浮盈留一半，把隔夜筹码的兑换单自己接下来。**

短线最贵的错误：出货区舍不得走，杀跌区等不及买，均线下面把货砸掉，赚了却全仓继续赌，暴击日还在科技里抄，隔夜还去猜明天会炒什么新故事，10:40 到 14:40 还在开新仓，开盘瀑布里还在市价逃命，盈利拿不住、亏损却越扛越大，高开 3% 还不跑。

## 每日复盘清单

- [ ] 昨日半导体（或当前主线）是否出现放量抛单？要不要次日一开盘就切走？
- [ ] 银行（大行 / 股份行）和春分动力昨日是承接、抗跌，还是一起跌？接得住才能轮。
- [ ] 持仓或自选里，有没有大跌股？若有，今天开盘是否已经强制自己「不操作」？
- [ ] 今天想追的票，**昨天是不是也在涨**？不是，就不要幻想开盘直接拉。
- [ ] 所谓底部，是已经看到止跌信号，还是只是「跌多了该反弹了」？
- [ ] 今天要卖的票，现价在不在分时均价上方？在下面的话，是不是还能等一次回抽再走？
- [ ] 隔夜短线仓开盘是否已经赚钱？赚钱的话，**1/2 是否已经在开盘卖掉**，而不是还在全仓等更高？
- [ ] 留下的那一半，有没有重新按规则三管理，而不是「留了就等于可以拿到收盘」？
- [ ] 今天是不是「大盘暴击 + 科技大规模下跌」？若是，科技仓是否已经在减，有没有去抄科技？
- [ ] 轮动是否先看了银行？港口、焦炭、煤炭、军工电子、地产、贵金属里，哪些是真有承接，哪些只是名单上的名字？
- [ ] 今天赚钱效应在哪个板块？涨停是否集中，还是各自为战？
- [ ] 主线是启动 / 发酵 / 高潮 / 退潮？明天更可能是延续、补涨，还是切换？
- [ ] 尾盘 30 分钟：主线是抢筹还是砸盘？有没有新方向尾盘异动？
- [ ] 主线还有没有余粮（低位中军今天已经在涨）？
- [ ] 今晚催化是确认已有方向，还是在诱你去猜新题材？
- [ ] 想隔夜的票，**今天是不是已经在涨**？不是，就划掉。是高潮龙头，也不隔夜
- [ ] 隔夜仓是否够小？三种埋伏是否只选了一种？次日竞价弱开的离场计划写好了没有？
- [ ] 今天每一笔买入，是不是落在 **10:40 之前或 14:40 之后**？中间有没有手痒开新仓？
- [ ] 10:40–14:40 是否做到了只卖不买？午后拉起来的票，有没有忍到 14:40 再决定？
- [ ] 开盘若急转直下，有没有先停手 3 分钟，而不是在瀑布里市价砸？
- [ ] 急转时想卖，是计划要走，还是害怕？现价在不在均线下方？有没有等到第一下回抽？
- [ ] 这笔隔日仓，盘前有没有写死：开盘走 1/2、剩余动态止盈、止损 -3%（最多 -5%）？
- [ ] 盈利的剩下 1/2，是按最高点回落 3% 走的，还是因为怕回吐提前砍完的？
- [ ] 亏损有没有触及止损还不走、改口等回本？条件单挂了没有？
- [ ] 收盘日志写了没有：买入理由、预定卖出信号、实际卖出、有没有被情绪改掉？
- [ ] 今天有没有高开 3% 及以上的持仓？有的话，开盘是否已经卖掉一半以上，而不是还在等更高？
- [ ] 高开 3% 之后，有没有把已经卖掉的仓位再买回来追？

## 纪律（写给自己）

1. 半导体抛压一旦确认，清仓优先于找下一笔利润。
2. 大跌后的开盘，默认禁止开新仓、禁止补仓。
3. 没有「昨涨」作为前提，就不要做「今开盘直接涨」的交易。
4. 轮动失败（银行也接不住）时，可以空仓，不必为了有仓位而买。
5. 抛出尽可能在日内均线上方完成；均线下方默认不砸盘、不接飞刀。
6. 短线第二天开盘赚钱，必须先走 1/2；禁止全仓留下来继续奔跑。
7. 市场暴击、科技大规模下跌时，科技只出不进；转看银行（最好），以及航运港口、焦炭、煤炭开采、军工电子、房地产、贵金属。
8. 次日热点只埋伏「今天已经在涨、还没走完」的方向；不猜全新题材，不隔夜扛高潮龙头，不埋伏今天大跌的超跌。
9. 隔夜仓必须小；尾盘确认后才允许锁仓。次日竞价弱开视为埋伏失败，开盘按计划处理，不扛。
10. 买入只允许在 10:40 之前和 14:40 之后；10:40 到 14:40 只卖不买，不准开新仓、不准补仓。
11. 开盘急转直下，第一反应是停手，不是下单。不在瀑布里砸；等第一下回抽或回到均线再卖。
12. 隔日仓盘前写死卖出：赚则开盘走 1/2，剩余用动态止盈（最高点回落 3%）让利润跑；亏则 -3%（最多 -5%）硬止损，不准等回本。
13. 买入同时挂止损条件单；每天收盘写交易日志。先让盈亏比为正，再谈胜率。
14. 高开 3% 及以上，刚开始就抛一半以上（默认 2/3）；这是隔夜筹码兑换窗，尽可能快跑，禁止追买。
15. 本页只记录已验证的短线习惯；新的体会按规则十一往后写，不临时改已经亏过钱的纪律。
