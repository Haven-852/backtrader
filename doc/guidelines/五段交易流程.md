# 五段交易流程：入选 → 观察 → 买入 → 持有/调仓 → 卖出

一套规则打所有股票、所有阶段，一定会出现某段时间失效。
把「选谁」和「何时买」拆开：先用不同方法入选，只观察；出现买入条件才动手；持有中按阶梯调仓；出现卖出条件或策略离场再走。

这不是再发明一套指标，而是把现有 A/B/C 选股、MA60 两套机制、高龄阶梯、沪深300阶段统计，收成同一条执行链。

## 0. 先看大盘阶段（每天收盘后）

用沪深300当日均线（只用到当天，不用事后牛熊）：

| 阶段 | 判定 | 默认态度 |
|---|---|---|
| 上升趋势 | 收盘 > MA20 > MA60 | 只做升势回踩、斜率转正、趋势持有 |
| 下降趋势 | 收盘 < MA20 < MA60 | 只观察或深折价短线，不做追涨 |
| 震荡 | 均线纠缠 | 缩量折价、回踩可以，仓位减半 |
| 高波动 | 近20日波动高于近120日80分位 | 禁止新开仓，已有仓只允许减、允许策略卖出 |

跨股回测里的「信号 × 阶段」表：当前阶段样本不足（默认 < 8 次）只观察；中位收益为负则暂停该信号。

## 1. 入选（选股，不是买入）

同一天可以用几种方法进池，互不合并成「立刻买」：

| 通道 | 系统里叫什么 | 入选后状态 | 含义 |
|---|---|---|---|
| A | 观察池：大跌后缩量筑底、靠近20日低点、MA5走平 | **只观察** | 形态可能转弯，还没有买点 |
| B | 升势回踩 MA5 | 待买入 | 已经在升势里，等回踩质量 |
| C | 趋势回踩：MA10>MA20，缩量回踩 MA10，风险≤4% | 待买入 | 结构短线，次日开盘才买 |
| MA60-A | 收盘 < MA60，缩量折价或深折价放量 | 待买入（短线） | 均线下方的折价 |
| MA60-B | 收盘 > MA60，且近10日里至少8日斜率为正 | 待买入（趋势） | 均线上方的升势 |

硬约束：

- 入选 ≠ 买入。A 通道永远不能当天当买入。
- 同一标的同时只走一条通道、只做一套仓位。
- 股票池按区间初期流动性选，不要用后来谁涨得多来挑赢家。
- 单日观察池上限 50；推荐池由观察池起飞后再进，不直接从全市场跳到买入。

## 2. 观察（等条件，不等感觉）

观察池里每天只做三件事：还在不在、有没有买点、该不该剔除。

继续留在池子：

- 仍满足入选形态，或尚未走坏（未放量跌破关键均线）。
- 大盘阶段没有切到「高波动禁止开仓」。

从池子拿掉（仍未买入）：

- 缩量变放量下跌，或收盘跌破观察时的结构低点。
- 超过约 20 个交易日仍无买入条件（过期）。
- 阶段统计里，该通道对应信号在当前阶段为「暂停」。

观察池 → 推荐池（起飞，已有流水线）：

- 放量约 1.3 倍、站上 MA5/MA10、突破颈线约 1%，可叠加板块共振。
- 起飞只是「允许进入待买名单」，仍要等第 3 步的买入条件。

## 3. 买入（条件触发，收盘确认）

必须同时满足：在待买名单里、当前阶段允许该信号、当天出现买入条件。

**升势（或个股机制 B）**

- 斜率刚转正：当天可买。
- 贴近 MA60（默认 2% 内）、站上 MA5 和 MA20、不放量：开仓或补仓。
- C 通道：收盘出信号，**次日开盘买**；相对信号日收盘高开超过 1% 则放弃追价。

**均线下方（机制 A）**

- 缩量折价（偏离 MA60 达到阈值、实体不大）：次日开盘买。
- 深折价 ≥15% 且量远超前 5 日：当天买。
- 趋势回踩必须站上 MA5/MA20，禁止跌破途中抄半山腰。

共性：

- A 股 T+1：买入当天不能卖。
- 开仓仓位按总资产比例、整手 100 股；研究上不要默认 100% 满仓，跨股检验用 30% 更稳。
- 当前阶段该信号在统计里为「暂停」则跳过，即使形态看起来一样。

## 4. 持有 / 调仓（没有策略卖点时才按表）

策略卖点优先：有离场信号就全清，不再走阶梯。

没有离场信号时，相对开仓价按高龄阶梯（每档只触发一次）：

- 跌 5%：不动。
- 跌 15%：增持 10%。
- 跌 25%：再增持 25%。
- 涨 5%、15%：继续持有。
- 涨 25% / 35% / 45% / 60%：分别卖 10% / 20% / 30% / 40%。
- 涨 100%：清仓。

机制 B 趋势持有期间：不要因为价格远离均线就卖；回踩贴近 MA60 且不放量、站上 MA5/MA20 才补仓，补仓次数有上限。

## 5. 卖出（条件触发）

按当时机制选卖点，不要混用：

**机制 A（价在 MA60 下，或尚未确认升势）**

- 反弹到 MA20 且放量：短线兑现。
- 深折价仓站上 MA5、量超前几日、收长阴：卖。
- 远超 MA60 且放量、或远离 MA5 且放量：卖。
- 跌破 MA60：离场。

**机制 B（价在 MA60 上且升势已确认）**

- 关闭「远超均线就卖」。
- 相对近 60 日量能中位数放量，最高价超过 MA5，相对 MA60 已到高位，并收出十字星（阴阳都算）：当天卖。
- 卖出后 5 日价格仍常大涨，该卖点在当前阶段记为「慎用」（容易卖早）。

**C 通道短线**

- 收盘跌破 MA10 且放量：次日开盘离场。
- 浮盈达 2R 后，止损上移为持仓最高价 − 2.5×ATR。
- 最多持有约 5 个交易日。

**推荐池衰竭**

- 动能衰竭则出推荐池；若仍持仓，按上面卖点处理，不要因为「还在自选」就留着。

高位十字星兑现后，在升势再次确认前，不要用机制 A 去接主升浪后的阴跌。

## 每天怎么做（对照页面）

1. 策略分析 → 观察池 / 升势回踩：勾选 A/B/C，看当日入选。
2. 「跑推荐流水线」：观察池 → 起飞 → 推荐池 / 衰竭出池。A 仍然只观察。
3. 跨股稳健回测：看当前沪深300阶段，以及哪些买卖信号是采用 / 暂停。
4. 待买名单里出现第 3 步条件，才下单或写入模拟账户。
5. 持仓中：无卖点则高龄阶梯；有卖点则全清。
6. 单票回测只用来核对买卖点，不能代替跨股确认区。

## 这条流程为什么管用

- 入选解决「看谁」，买入解决「何时」，两者分开，避免形态刚出现就追。
- 观察是过滤器：大多数入选不会买，这是正常的。
- 阶段统计避免在下降趋势里复用上升趋势的买点。
- 调仓和卖出分层：阶梯管仓位，信号管对不对。

仍会失效的情况：阶段切得慢、某信号样本太少、涨跌停/停牌无法成交。回测已扣佣金和印花税，但不含这些摩擦。只作研究流程，不构成投资建议。
